## The problem

Customers message businesses on WhatsApp at all hours, and most of the questions are the same: prices, opening times, availability, order status. Answering them by hand is slow, and slow replies lose customers.

## What I built

A WhatsApp assistant that runs as an **n8n workflow** with **Groq** for the language model.

- **WhatsApp Cloud API webhook.** Every incoming message triggers the workflow.
- **Context first.** The workflow loads the conversation history and the business's information before the model replies.
- **Groq for speed.** Open models on Groq's inference hardware answer in a fraction of the time of a typical API call, so the chat feels instant.
- **Human hand-off.** When the question is out of scope or the customer asks for a person, the chat is flagged for the team.
- **No black box.** The whole flow is visible in n8n, so the business can change messages and rules without code.
